# CLI Overview

| Command | Purpose |
|---|---|
| [`fracta init`](/reference/cli/init) | Initialize `.fracta` in a git repo |
| [`fracta spawn`](/reference/cli/spawn) | Spawn a new agent with a task |
| [`fracta list`](/reference/cli/list) | List all agents, status, and intent |
| [`fracta peek`](/reference/cli/peek) | Show an agent's recent semantic output |
| [`fracta say`](/reference/cli/say) | Send a follow-up message to an agent |
| [`fracta watch`](/reference/cli/watch) | Stream live SSE events from an agent |
| [`fracta merge`](/reference/cli/merge) | Merge an agent's branch into the current branch |
| [`fracta kill`](/reference/cli/kill) | Remove an agent's worktree and state |
| [`fracta serve`](/reference/cli/serve) | Run fracta as an MCP server |
| [`fracta controlplane`](/reference/cli/controlplane) | Manage the control plane daemon |
| [`fracta worker`](/reference/cli/worker) | Run a queue worker for missions |
| [`fracta host-mcp`](/reference/cli/host-mcp) | Run the host-facing MCP server |
| [`fracta auth`](/reference/cli/auth) | Manage credential profiles |
| [`fracta mcp`](/reference/cli/mcp) | Manage MCP server auth and credentials |
| [`fracta registry`](/reference/cli/registry) | Manage MCP server / tool registrations |
| [`fracta graph`](/reference/cli/graph) | Query and update the knowledge graph |
